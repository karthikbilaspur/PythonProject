TEXT TOOLKIT - 4 tools + 1 launcher
Run: python app.py
Files:
 app.py - launcher menu
 sentiment.py - sentiment + wordcloud
 summarizer.py - frequency summarizer
 analyser.py - word counts / stats
 sheets.py - Google Sheets (needs credentials.json + Sheet Name set inside sheets.py)
Install: pip install nltk wordcloud matplotlib pandas gspread google-auth
Sheets: share your sheet with the service-account email in credentials.json
